Calculadora Básica



Descripción



Calculadora Básica es una aplicación web sencilla que permite realizar operaciones matemáticas fundamentales utilizando dos números ingresados por el usuario. El proyecto fue desarrollado con el propósito de aplicar conceptos de programación y buenas prácticas de control de versiones mediante Git y GitHub.



Objetivo



Desarrollar una aplicación web funcional que permita realizar operaciones matemáticas básicas y gestión de versiones de un proyecto de software.



Funcionalidades



\- Ingreso de dos números.

\- Suma de valores.

\- Resta de valores.

\- Multiplicación de valores.

\- División de valores.

\- Validación de datos ingresados.

\- Validación de división entre cero.

\- Limpieza de los campos ingresados.

\- Interfaz visual mediante CSS.



Tecnologías utilizadas



\- HTML5

\- CSS3

\- JavaScript

\- Git

\- GitHub

\- Bloc de notas como editor de código



Estructura del proyecto



\- `index.html`: contiene la estructura principal de la calculadora.

\- `style.css`: contiene los estilos visuales de la aplicación.

\- `app.js`: contiene la lógica y las funciones de la calculadora.

\- `.gitignore`: especifica los archivos y carpetas que Git debe ignorar.

\- `README.md`: contiene la documentación general del proyecto.



Instalación o ejecución



1\. Clonar o descargar el repositorio.

2\. Abrir la carpeta `calculadora-basica`.

3\. Localizar el archivo `index.html`.

4\. Abrir `index.html` utilizando un navegador web.

5\. Ingresar dos números.

6\. Seleccionar la operación matemática que se desea realizar.



No es necesario instalar dependencias adicionales para ejecutar el proyecto.
